# 개인 공통 작업 지침

## 1. 필수 정책 읽기

실제 사용자 홈의 `.agents/skills/governance-default/references/default-policy.md`를 읽습니다. 사용자 홈과 Codex home은 다를 수 있습니다. 경로는 현재 runtime의 사용자 홈에서 찾으며 이 파일의 부모를 사용자 홈으로 간주하지 않습니다.

정책 SHA-256 고정값은 `{{DEFAULT_POLICY_SHA256}}`입니다. 파일을 읽고 수정 전 해시를 대조합니다. 이 세션에서 같은 파일·해시를 이미 확인했다면 다시 본문을 읽지 않습니다. 필수 정책 누락·읽기 거부·해시 불일치가 해결될 때까지 해당 정책이 필요한 수정·게시·운영 적용·완료 판정을 중단하고 원인을 보고합니다. 원인 확인과 영향받지 않는 읽기 작업은 계속할 수 있습니다.

## 2. 작업 범위

현재 사용자 요청과 플랫폼 지침·관리 정책·OS 권한을 따릅니다. 저장소의 `AGENTS.md`와 관련 운영·검증 지침을 읽습니다. 승인된 범위의 작업은 계속 진행하고 기존 사용자 변경을 보존합니다. 지침 파일은 실행 권한을 부여하지 않습니다.

한국어로 실행 목적·관찰·다음 조치를 간결하게 설명합니다. 검증은 통과·부분 검사·실패·미실행을 구분합니다. 작업에 필요한 전문 skill만 선택하고 요청하지 않은 설치·게시·운영 적용으로 확대하지 않습니다.
