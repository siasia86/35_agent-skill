# Using skills

Read the mandatory policy entrypoints from applicable AGENTS.md first; skill selection alone does not guarantee policy loading. Begin with the user’s goal and applicable instructions. Select only skills that materially help: governance for repository rules; planning/specification for substantial infrastructure work; debugging for failures; review/security/testing for their named purposes; templates for scripts or documentation; release checks for shipping. Use a small composition when tasks genuinely span these concerns.

Do not require every available skill for every task, and do not treat a skill as permission for deployment, deletion, credential use, or external access. If a referenced skill is unavailable, continue with a safe equivalent and disclose that limitation. Resolve conflicts in favor of platform policy, user direction, and applicable repository guidance.
