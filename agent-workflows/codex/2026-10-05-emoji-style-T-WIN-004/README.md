## 1. 최신 요청과 담당

2026-10-05 개인 표현 규칙 후속입니다. 시작 기준은 SKILL-35 main `b04b034e479a3d69fd8795620230bf11fb4647b8`이며 기존 ID는 T-WIN-004입니다. 최초 엄격한 7개 제한 요청은 사용자의 후속 정정으로 대체됐고 그 가정으로 원본·설치본을 수정하지 않았습니다.

## 2. 원본과 실제 소비자

배포용 scripts/md-style-check.py를 호출하는 7개 skill을 확인했습니다: work-rules, md-link-check, git-commit-rule, readme-template, security-tools, using-skills, zircon-readme-policy. 현행 검증기의 동일 helper 사본 계약도 확인하여 이 7곳의 실행 사본과 활성 STYLE만 맞췄습니다. originals·linux-tools·backup·system·plugin은 변경하지 않았습니다.

STYLE의 별점 허용을 유지하고 보조 기호를 명시했습니다. 기존의 보조 설명 아이콘 전면 금지 문구는 필요한 때 사용할 수 있도록 보완했습니다. 상태 7개에 기존 공백 규칙을 적용하며 보조 기호·별점에 새 공백 규칙을 강제하지 않습니다.

검사기 버전은 `26.10.05`입니다. [Unicode Emoji 데이터 15.1](https://www.unicode.org/Public/15.1.0/ucd/emoji/emoji-data.txt)의 Emoji 속성 1,424개 코드 지점을 사용하여 BMP·국기·키캡·변형 선택자와 결합 표기를 검사합니다. 단독 허용 기호의 VS15·VS16 표시 차이는 허용하지만 기호를 바꾸는 피부톤·ZWJ·키캡 결합과 비허용 기호는 별도로 판정합니다. 일반 수학 문자·텍스트형 화살표·숫자를 모두 이모지로 취급하지 않습니다. 데이터 버전은 고정했으며 향후 Unicode 추가 기호는 미검증 범위입니다.

정확한 fenced·inline·들여쓰기 코드와 직접 인용, inline 링크 목적지의 원문을 보존합니다. 들여쓰기 코드는 문단을 중단할 수 없고 목록 안에서는 컨테이너 기준 네 칸을 추가로 요구하도록 구분했습니다. 코드 다음의 새 설명과 목록의 일반 설명은 계속 검사합니다. 이 도구는 전체 Markdown 렌더러를 구현한 것은 아닙니다.

## 3. 보존과 지정 설치
