# CU-TURN-20261004-01 Computer Use 시작과 제어 종료

## 1. 범위와 변경

사용자 요청에 따라 [개인 work-rules](../../../codex_windows/skills/work-rules/SKILL.md)의 실행 규칙을 보완합니다. 같은 화면·입력을 제어하기 전에 대상·작업·대기 시간을 안내하고 5~10초 기다립니다. 응답이 없으면 기존 승인 범위에서 진행하고, 중단·연기·수정 요청을 먼저 반영합니다. 필수 확인·승인이 필요한 행동에 무응답을 승인으로 적용하지 않습니다.

작업 구간을 마치면 제어 종료를 안내하고 지원되는 세션 해제·초기화를 수행합니다. 다음 제어가 필요하면 새 안내·대기 후 재개합니다. 사용자 입력과 충돌하면 조작을 멈추고 상태를 확인하며 업무 앱 종료는 해당 작업의 승인 범위를 따릅니다. bundled Computer Use·system skill·개인 설정은 수정하지 않습니다.

작업 ID는 CU-TURN-20261004-01입니다. 담당 파일과 예정 commit 파일은 work-rules/SKILL.md, Windows TODO의 같은 ID 항목, 이 기록입니다. 별도 기능 Goal·DB·게임·다른 저장소 작업은 변경하지 않습니다.

## 2. 보존과 검증

변경 전 관리 원본과 설치본 전체 폴더의 상대 파일 목록·크기·SHA-256을 대조하고 이전본을 이번 private/before에 보존합니다. 다른 설치 skill과 개인 설정도 해시로 비교하고 실제 개인 설정·raw는 Git 제외 private에만 둡니다. 원본 정적 검증 후 work-rules 전체 폴더를 지정 설치본에 반영하고 목록·해시 일치를 검사합니다.

원본·설치본 44파일의 변경 전 차이는 0건입니다. 공식 quick_validate·3개 문서 링크·헤딩 검사를 통과했고 표현 검사의 기존 skill 푸터 경고 3건은 그대로이며 신규 문제는 없습니다. 이전 전체 폴더를 보존한 뒤 로컬에 전체 폴더를 반영하여 목록·해시 일치를 확인했습니다. 다른 개인 skill 7개와 개인 설정 해시는 그대로입니다. 검증 결과와 설치 관찰은 [validation](validation.json)에 기록합니다. 정적 검사·설치 파일 일치는 실제 새 세션의 자동 선택이나 시간 대기·제어 종료 행동 검증이 아닙니다. 실제 행동 후속은 [Windows TODO](../windows/TODO.md)의 같은 ID로 유지합니다. 이 규칙을 검사하기 위한 데스크톱 조작은 실행하지 않습니다.

## 3. 게시와 복구

검토한 담당 파일만 main에 commit·일반 push하고 원격 SHA를 대조합니다. CI 결과와 원격 게시 결과를 구분합니다. 복구할 때 private/before의 전체 이전본·해시와 현재 사용자 변경을 먼저 비교하여 이번 수정 범위만 되돌립니다. 게시 이후 원본 복구는 검토한 revert로 진행합니다. 다른 skill·설정·plugin은 교체하지 않습니다.
