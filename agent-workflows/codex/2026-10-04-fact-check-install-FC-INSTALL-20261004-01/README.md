## 2. 적용과 검증

기존 개인 스킬 전체 101파일·개인 지침/config·관리 원본·담당 문서의 변경 전 사본과 해시를 Git 제외 private에 보존했습니다. 검증된 local source에 bundled skill-installer의 경로 검증·전체 폴더 복사 helper를 사용했습니다. 원격 다운로드나 재clone은 하지 않았습니다.

## 3. 발견과 사용

새 Luna 실행 문맥의 실제 제공 스킬 목록에 `fact-check`와 사용자 범위 SKILL 경로가 나타났다고 반환받았습니다. 관찰 담당은 파일 접근·검색·skill 호출을 하지 않았으므로 경로 존재 확인을 목록 발견으로 대신하지 않았습니다. root의 현재 목록 갱신과 실제 명시·암묵 호출 행동은 이 결과로 완료 표시하지 않습니다.

[공식 스킬 안내](https://learn.chatgpt.com/docs/build-skills)에 따라 Codex에서 다음처럼 호출할 수 있습니다.

기본은 문서 각각의 사실을 검증하고 확인된 오류만 최소 수정합니다. 수정 금지가 있으면 쓰지 않으며 추론·새 내용 추가를 금지합니다. 이번 설치는 임의의 PLAN·TODO 변경 요청이 아니므로 실제 프로젝트 문서를 사실 검증하지 않았습니다.
