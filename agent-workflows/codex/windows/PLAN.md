# Codex Windows 이관 계획

현재 범위는 Linux의 **19개 skill과 확인된 설정 전체의 Windows 이관**입니다. 원문을 축약·삭제·통합하지 않습니다. 작업 기준과 증거는 [이관 기록](../WINDOWS_MIGRATION_2026-10-03.md)에 두고 상태는 [TODO](TODO.md)에 연결합니다.

## 1. 전체 원본과 설정 확인

19개 이름·182개 파일·동봉 역할 54개·Python 도구 25개와 개인 공통 지침·저장소 config를 출처 manifest로 대응합니다. 활성 설정과 폐기한 `105_backup`의 agent/payload 예시를 구분합니다. 실제 개인 홈의 인증·MCP·모델 설정은 공개 자료에 복사하지 않습니다.

## 2. Windows 본문과 필요 도구 이관

각 skill의 전체 규약을 보존하고 Windows 호환 절·PowerShell/Python 실행 절차·로컬 참조·필요 도구를 작성합니다. Bash 역할은 Git Bash/WSL로 유지합니다. 플랫폼 차이와 기존 재현 결함은 최소 호환 수정으로 해결합니다. 모든 기존 파일을 보존 경로와 SHA-256으로 대조합니다.

## 3. 검증과 yunli 게시

메타데이터·원본 보존·단독 복사·UTF-8·정상/실패 입력·Markdown 문법·원자 쓰기·잠금 경쟁을 TEMP fixture에서 확인합니다. 실제 검사와 미실행 범위를 구분해 기록하고 yunli에 commit·일반 push합니다.

## 4. 사용자 검증과 main 반영

사용자가 yunli의 전체 이관 결과를 검증합니다. 필요한 보완 후 승인된 결과를 main에 반영·push합니다. 기존 사용자 변경과 Linux 원본을 보존합니다. 게시 후 복구는 검토된 revert를 사용합니다.

## 5. 이관 이후 최적화

전체 이관과 사용자 검증 이후 실제 사용 사례를 기준으로 최적화를 진행합니다. 스킬 생략·축약·통합·모델/MCP 변경을 이번 이관의 완료 조건으로 적용하지 않습니다. 실제 홈 적용과 발견은 별도 상태로 기록합니다.
