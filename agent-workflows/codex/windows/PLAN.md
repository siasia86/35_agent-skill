[이번 갱신·검증·복구](../2026-10-04-orchestration-T-WIN-004/README.md)에 실제 범위를 연결하며 fact-check의 FC-INSTALL 지정 설치 완료와 TODO의 남은 행동은 구분합니다.

### 2026-10-09 Git 통합 목표와 차기 순서

이번 사용자 명시 지시에 따라 `MAIN-20261004-01·T-WIN-002/004`의 통합 담당 Goal을 생성했습니다. 목표는 기존 계획·상태를 수신 근거에 연결하고, 확정 인계된 변경만 직렬 검증·main 게시·실제 원격 SHA 확인까지 마감하는 것입니다. 기능·설치·DB·운영 적용과 미완료 행동의 완료 판정은 이 Goal의 범위가 아닙니다.

- **담당·환경·파일:** `35 · Git 통합`이 Windows PowerShell·Python·Git에서 staging·commit·push를 단독 수행합니다. 이번 후보는 [STYLE 교정 기록](../2026-10-09-style-diagnostics-T-WIN-004/README.md)의 STYLE·README 2개와 이 PLAN·Windows TODO·공통 HANDOFF·CHANGELOG의 필요한 갱신입니다. 개인 설치본·AGENTS·설정·검사기·다른 skill·게임·DB·인계 전 후속 초안은 제외합니다.
- **P0 / 완료 근거 재사용:** FC delta 결과 2개와 관리 기록은 [3d435614](https://github.com/siasia86/35_agent-skill/commit/3d435614658b2ac6427c1d50c421dd7bfbac9718)에 게시됐으므로 재게시·계산 재실행하지 않습니다. `V-D02`와 기존 FC/FCH 미확인은 유지합니다.
- **P1 / 인수와 의존성:** 소유 담당의 검증·지정 설치·쓰기 종료·최종 후보 해시가 선행입니다. 확정 STYLE·README 2개를 대조하고 기존 진단 12→8 및 관리 44파일 설치·사본 보존의 소유 근거를 인수합니다. 공개 결과와 현재 파일 핀이 달라지면 영향 구간의 인수를 중단하고 원인을 확인합니다.
- **P2 / 계획·기록 검증:** 현재 목표·담당/제외 파일·우선순위·재개 조건을 기존 PLAN·TODO에 연결하고 의미 검토 1회와 변경한 관리 문서의 검사만 수행합니다. 같은 입력의 소유 검사·설치 대조는 재사용합니다. 정형 검사·Git 실행은 Luna `gpt-6-luna / medium`, 범위·판정·통합 결정은 소유 담당이 맡습니다.
- **P3 / 게시와 완료 조건:** 검토한 실제 파일 집합과 index blob을 대조하고 diff·비밀값 검사를 통과한 뒤 main 일반 commit·push·실제 원격 SHA 일치를 확인합니다. 완료 조건은 계획의 실행 가능성, 기존 미완료·보류·다른 작업 보존, 지정 변경의 검증·게시 근거와 다음 조건의 연결입니다. 실제 결과는 최종 게시 영수증·종료 보고로 확인하며 전체 T-WIN-004의 완료로 확대하지 않습니다.
- **복구·실패:** 게시 전에는 현재 해시와 Git 제외 이전 사본을 대조해 이번 담당 diff만 선택 복원하고 이후 사용자 변경을 보존합니다. 게시 후 복구는 검토한 revert로 진행합니다. 설치본·다른 작업·설정은 통합 담당의 복구 대상이 아니며 검사·게시 실패 시 영향 단계만 중단하고 증거·원인·재개 조건을 기록합니다.
