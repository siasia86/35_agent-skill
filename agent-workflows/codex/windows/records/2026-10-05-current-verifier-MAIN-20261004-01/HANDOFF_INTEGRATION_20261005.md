## 3. 실행 순서·검증·복구

선행 인계·입력핀 대조 → 이번 Goal 설정 → 해당 PLAN/TODO·재개 안내 채택 → 의미 검토 → 변경 영향 문서 검사·앵커 대조·비밀값 검사 → 담당 6개만 main 일반 commit·push·실제 원격 SHA 확인 순서입니다. 입력이 같은 원본·설치·공식 validator·과거 회귀 검사는 재사용합니다. 직접 수정한 문서와 새 인계 파일의 검사 범위·결과는 private 검사 로그에 남깁니다.

완료 조건은 소유 근거와 현행 안내의 일치, 기존 미완료·보류 유지, 담당 문서·링크·앵커·diff·비밀값 검사 통과와 지정 게시·원격 SHA 확인입니다. 일부 문서나 후보 인수로 전체 기능 완료를 주장하지 않습니다. 이후 변경·충돌은 영향받은 파일만 조율하고 다른 독립 승인 구간은 계속합니다.
