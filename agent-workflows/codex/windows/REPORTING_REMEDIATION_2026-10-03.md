# Windows 공통 보고 지침과 helper 보완 — 2026-10-03

시작 기준은 `yunli@47f3328`입니다. 사용자가 지정한 `codex_windows/personal/AGENTS.md`와 주로 사용하는 work-rules에 공통 보고 지침을 반영하고, [이전 개선 검토](IMPROVEMENT_REVIEW_2026-10-03.md)의 W02–W10을 수정했습니다. Linux·Kiro·이관 당시 결과·개인 홈은 보존합니다.

당시 personal/AGENTS.md 배치는 과거 수행 사실로 보존합니다. 현행 파일은 [배포 원본 AGENTS](../../../codex_windows/AGENTS.md)이며 [T-WIN-002 배치 교정](../../history/2026-10-03/T-WIN-002-distribution-root.md)에서 이동·검증 근거를 확인합니다.

## 1. 기준 본문과 실제 반영

실행 지침: `codex_windows/`.

- [work-rules](../../../codex_windows/skills/work-rules/SKILL.md#작업-시작과-완료-보고)에 시작 전 대상·수행·예상 결과, 의미 있는 진행 관찰, 완료 후 수행·검증·미실행과 잘된 점·문제·제약을 기록했습니다. 같은 동봉 역할 2곳도 일치시켰습니다.
- [개인 공통 AGENTS](../../../codex_windows/AGENTS.md#작업-시작과-완료-보고)는 같은 기본값을 짧게 제공하고 work-rules로 연결합니다. 사용자가 지정한 저장소 파일이며 실제 홈 AGENTS를 설치·교체한 상태가 아닙니다.
- 결과물이 있으면 설명 위에 기준 경로와 파일 링크를 표시합니다. 큰 결과는 표·번호 목록·트리 중 내용에 맞는 형식을 선택하고 짧은 답변에 고정 양식·깊은 중첩을 강제하지 않습니다.
- 채팅의 `;`는 여러 요청을 구분하는 뜻으로 이해합니다. 각 요청의 진행·검증·미실행을 구분하고 코드·명령어·인용문·경로 안의 기호는 원래 의미를 유지합니다.
- 중앙 31의 [35 정책](https://github.com/siasia86/31_governances/blob/yunli/profiles/codex/repositories/35_agent-skill.md#3-개인-codex-공통-보고-지침의-구현-기준)은 구현·관리 기준입니다. runtime의 사용을 위해 31 조회·설치나 다른 skill을 필수로 요구하지 않습니다. 중앙 draft·정책 게시와 실제 홈 적용을 구분합니다.

## 4. 게시와 복구

검증한 변경을 yunli에 일반 commit·push한 뒤 사용자 검증을 기다립니다. 실제 게시 SHA는 Git refs와 작업 완료 보고에서 확인합니다. 사용자 검증 전 main 병합·push, 실제 개인 홈 설치·config 변경·운영 적용은 수행하지 않습니다.

수정 범위는 Windows 활성 호환 본문·helper·선택적 공통 지침과 외부 개발 문서·회귀 코드입니다. 보호 원문·출처 manifest·과거 검사 JSON은 바꾸지 않습니다. 게시 후 되돌릴 필요가 있으면 해당 보완 커밋을 검토하여 revert하며 다른 작업·원문·실제 홈은 보존합니다. 홈 적용은 수행하지 않아 홈 복구 작업도 발생하지 않았습니다.

## 5. Luna 우선 배정 후속

후속 시작 기준은 `yunli@f4514a5`입니다. 사용자는 workflow 설계는 출력만 유지하고 Luna 배정 규칙만 35의 work-rules·personal AGENTS에 반영하도록 지정했습니다. 실제 문서 이동·개편·중앙 31 변경·개인 홈 적용·기본 모델 설정 변경은 수행하지 않습니다.

[work-rules의 Luna 배정 기준](../../../codex_windows/skills/work-rules/SKILL.md#luna-우선-배정과-main-ai의-검증)은 정해진 범위의 검색·조회·추출·정형 대조를 우선 위임하고 main AI가 의미 판단·핵심 근거·최종 검증을 담당하도록 합니다. 작은 호출의 과도한 분할, 미지원 상태를 실제 Luna 실행으로 표시, 도구 오류를 사실 없음으로 처리하는 동작을 피합니다. 실제 환경에서 사용 가능한 사용자 지정 Luna와 도구의 선택 기능을 확인합니다.

직접 지정한 `gpt-6-luna`·low의 읽기 전용 조회 사례에서 첫 복합 PowerShell 명령은 파서 오류였고, 단순 명령으로 한 번 재조회해 Git 상태·문서 6개의 제목·TODO 체크 수를 보고했습니다. main AI가 원본 값과 오류/누락을 대조합니다. 이 사례는 직접 모델을 선택한 분담이며 새 지침의 자동 선택·홈 설치·전체 workflow 적용을 검증한 것은 아닙니다.

후속 검사는 본문 3사본 일치·활성 절 검사 3종, 출처 182파일·설정2개와 호환 블록 밖 원문73개 보존, 독립 복사298파일·metadata19개·안내 링크28개·helper36개 bytes 일치·개발 CLI4개를 통과했습니다. 현행 안내21개 style·heading·로컬 링크와 교차 fragment48개, 비밀정보 탐지0건·Git diff도 통과했습니다. main AI가 TODO 완료11개·미완료7개를 원본과 재대조했습니다.

Luna의 독립 검사 호출은 TEMP 권한 오류로 중단되어 통과로 기록하지 않았습니다. main AI가 권한을 갖춘 실행으로 기존 검증 도구를 다시 실행해 19개 skill·동봉54역할·필수 참조214개·Python AST34개·독립 실행41회를 확인했습니다. 기존 W02–W10 실행 결과는 위 3절의 당시 검증으로 유지하며 이번 지침 변경 때문에 이전 회귀를 새 실행으로 표시하지 않습니다.
