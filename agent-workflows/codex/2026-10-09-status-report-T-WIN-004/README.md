## 7. 보존과 복구

비공개 `private`는 Git 제외를 확인한 기존 기록 공간입니다. 실제 개인 경로·부록·raw·전체 설정은 공개 후보에 포함하지 않습니다.

- `before/source`와 `before/local`: 변경 전 전체 지정 범위와 해시.
- `after/source`와 `after/local`: 최초 설치 후 사본과 해시.
- `behavior-refinement/v1-source`와 `v1-local`: 보강 직전 2파일.
- `behavior-refinement/v2-source`와 `v2-local`: 보강 후 2파일과 설치 기록.
- 검사·관찰·읽기량·정정 이전 기록·최종 후보 manifest: 단계별 근거.

복구할 때는 현재 사용자 차이를 먼저 대조하고 지정 범위만 복원합니다. work-rules는 이전 관리 파일과 로컬 전용 차이를 보존하며, 개인 AGENTS는 공통부만 복구하고 부록과 줄바꿈을 유지합니다. 신규 skill은 변경 전 없었으므로 이번 설치 파일인지 확인한 뒤 처리하고, 이후 생긴 사용자 파일을 일괄 삭제하지 않습니다.

실행 과정의 PowerShell 입력 파싱 실패, helper의 목록 순서·BOM 처리 오류, 캐시 생성 권한 거부는 원본 쓰기 전 오류로 구분했습니다. 최초 after 사본의 중첩 경로 누락은 이미 설치가 완료된 뒤 발생했고 기존 사본 해시를 확인한 후 누락 사본만 채웠습니다. 이전본 README 검사 경로 문제도 원본 링크 문맥을 보존한 사본으로 바로잡았습니다. 실패 기록은 성공 기록으로 덮어쓰지 않았습니다.
