# T-WIN-004 Luna 수집 배정과 토큰 사용 보완

## 1. 범위와 기준

사용자의 간단한 자료 수집 Luna 재사용·Luna 6.0 최소 모델 요청을 반영합니다. 기존 [T-WIN-004 후속](../windows/TODO.md)의 조건별 모델 배정 범위이며 기능 상태나 새 Goal을 만들지 않습니다. 이전 [모델·역할 기록](../2026-10-04-orchestration-T-WIN-004/README.md)은 당시 결과로 보존합니다.

담당 파일은 [work-rules 본문](../../../codex_windows/skills/work-rules/SKILL.md), [운영 상세](../../../codex_windows/skills/work-rules/references/operating-details.md)와 이번 기록입니다. 다른 담당의 fact-check 작업과 공통 PLAN·TODO·CHANGELOG 변경은 보존하고 이번 staging에 포함하지 않습니다.

- 지정 자료·추출 규칙이 명확한 단순 수집은 Luna 6.0의 실제 지원 최저 effort로 배정합니다. 이번 위임 도구의 지원 값은 `gpt-6-luna / low`이며 미지원 `minimal`을 요청하지 않습니다.
- 짧은 조회는 직접 처리하고 관련 추출은 묶습니다. 기존 조사·통과 검사를 재사용하고 반환은 근거·개수·예외로 제한합니다.
- 자료 검색·선별·출처 판단과 복잡한 분석의 기존 모델 기준을 유지합니다. 오류·모호함·의미 판단이 필요한 구간만 root 또는 적합한 모델에 인계합니다.
- 개인 AGENTS·설정·다른 skill·중앙 정책은 이번 변경 범위 밖입니다. 기존 fact-check 설치 대기를 유지합니다.

## 2. 검증과 설치 관찰

변경 전 원본·설치본의 전체 44파일과 SHA-256을 대조해 차이 0건을 확인하고 Git 제외 private/before에 두 전체 폴더·개인 지침·설정을 보존했습니다. 이번 정형 문구 추출은 실제 `gpt-6-luna / low`를 지정하여 위임했고 경로·행·요지 반환을 확인했습니다. 이 관찰은 변경한 skill의 새 세션 자동 선택·행동 검증과 구분합니다.

의미 검토 1회에서 짧은 직접 조회·정형 일괄 추출·출처 판단 전환·읽기 실패·동일 입력 재사용·모델 미지원의 처리 경로를 대조했습니다. 기존 승인·보류·필수 검증과 복잡한 판단의 모델 기준을 유지합니다. 이 검토는 실제 업무 시나리오를 모두 실행한 시험이 아닙니다.

원본과 설치본의 공식 skill-creator 구조 검사를 통과했습니다. 변경 Markdown 3개·링크 19개·헤딩 13개 검사와 문서 표현·git diff 검사를 통과했습니다. skill 문서 두 개는 기존 푸터 비강제 기준을 적용했습니다. 기존 격리 검증 의존성을 재사용했으며 패키지를 추가 설치하지 않았습니다.

원본의 지정 본문 두 파일만 변경했고 파일 추가·삭제 없이 work-rules 전체 44파일을 설치했습니다. 원본·설치본의 파일 목록·크기·SHA-256이 일치하며 다른 개인 skill 7개·개인 지침·설정의 변경 없음도 해시로 확인했습니다. 전체 before/after·검사 로그·복구 근거는 이번 Git 제외 private에 보존했습니다. 모델 성능 비교·토큰 절감량 측정·변경된 skill의 새 세션 자동 선택은 미실행입니다.

## 3. 복구와 후속

복구 전 현재 폴더와 이번 after 해시를 비교하여 이후 변경을 보존합니다. private/before의 work-rules 전체 폴더를 선택 복원하거나 이후 차이와 병합하며 다른 skill·설정을 일괄 덮어쓰지 않습니다. 공개 원본 복구는 담당 변경의 검토한 revert로 진행합니다.

새 세션의 발견·선택·실제 분담은 기존 T-WIN-004 후속에서 관찰합니다. 이번 설치·정적 검사만으로 해당 미완료 항목을 완료 처리하지 않습니다. 원격 게시 SHA는 게시 후 비공개 실행 기록과 완료 보고에서 연결합니다.
