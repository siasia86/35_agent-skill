# 사용자 행동 항목의 상태 표시 보완

## 1. 좁은 보완 범위

T-WIN-004 후속으로 [work-rules](../../../codex_windows/skills/work-rules/SKILL.md)와 현행 STYLE 사본 7개에 [사용자 행동 항목 바로 앞 표시](../../../codex_windows/skills/work-rules/references/STYLE.md#사용자-확인개입-안내)를 추가합니다. 사용자가 직접 수행할 확인·시험·입력은 🟡 확인, 선택·판단·조율은 🟠 조율 표시와 행동을 항목 제목 바로 앞에 둡니다. 요약 표의 표시로 실제 행동 항목 표시를 대신하지 않습니다. 담당이 검증한 근거는 ✅ 검증, 참고 자료는 🔵 정보 표시로 구분합니다.

경로·DLL·실행기·해시·commit을 나열했다고 사용자 확인 의무가 생기지 않습니다. 같은 자료에 실제 사용자 행동이 필요하면 그 행동을 명시하고 이미 검증한 해시·출처를 사용자에게 반복 확인시키지 않습니다. 이모지는 가시성을 높이는 표현 수단이며 기존 승인·보류·상태 원본·완료 판정과 허용 기호는 유지합니다. 개인 AGENTS·검사기·중앙 정책·게임·실행 환경은 변경하지 않습니다.

완료·중단·사용자 개입 대기로 이번 실행을 마감할 때는 현재 유효한 미해결 사용자 요청만 보고 맨 위에 다시 모아 안내합니다. 기존 상세 안내 링크를 재사용하고 이미 해결한 요청과 명시적 보류의 재요청은 제외합니다. 개입 사항이 없으면 없다고 짧게 알립니다. 보고 시점을 기능/Goal 완료로 해석하거나 자동 알림·별도 상태 원본을 추가하지 않습니다.

## 2. 보존·검증·적용

이번 갱신 전 원본 폴더 7개와 기존 설치 폴더 3개 전체를 별도 private/before에 해시와 함께 보존했습니다. 설치본과 원본의 내용 차이는 없었고 기존 캐시는 유지합니다. 의미 대조와 문서·skill 구조·동일 사본·검사기 보존 검증 결과는 [집계](validation.json)에 기록합니다. 검사기 코드가 같으므로 과거 기호 회귀 검사를 반복하지 않습니다.

검증한 원본을 기존 설치 대상 work-rules·git-commit-rule·md-link-check 3개 폴더 전체에 반영했습니다. 내용 파일 80개의 상대 목록·해시가 원본과 일치하고 기존 캐시 3개는 변경 없이 보존했습니다. 전체 설치 파일 83개는 private/after에 보존했습니다. 설치·파일 일치를 독립 새 세션의 장기 행동 검증으로 확대하지 않습니다. 담당 공개 파일과 기존 Windows TODO의 근거 연결만 단일 Git 통합 담당이 게시합니다. 개인 경로·전체 설치 사본·raw·전후 해시는 Git 제외 private에 보존합니다.

## 3. 복구와 남은 범위

복구 전 이후 변경을 대조하여 이번 담당 문구만 이전본으로 선택 복원합니다. 게시 후 원본 복구는 검토한 revert를 사용합니다. 기능 상태·사용자 보류·새 세션의 행동 미확인 항목은 기존 원본에 유지합니다. 이번 보완으로 새 시험·Goal·채팅·감시·권한·운영 적용을 추가하지 않습니다.
