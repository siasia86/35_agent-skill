## 3. 실제 변경과 보존

변경 파일은 [work-rules/references/STYLE.md](../../../codex_windows/skills/work-rules/references/STYLE.md) 한 개입니다. `Desk`, `System prompt`, `Chat history`, `Ref files (context)`, `Command complete`, `post hook`의 6개 라벨과 필요한 공백 패딩만 바꿨습니다. 책상 비유·구성 요소·실행 완료·후처리 흐름을 유지했습니다.

- 상자형 예시 6행은 변경 전후 모두 display width 70입니다.
- 흐름도 명령행 16, 해당 상자 행 17과 기존 선행 공백·화살표·연결·프롬프트를 유지했습니다.
- 두 선택 블록 밖의 bytes는 그대로이며 관리 파일 44개 중 다른 43개 SHA도 같습니다. 보존 originals와 Kiro 자료는 변경하지 않았습니다.
- STYLE은 28,457바이트에서 28,430바이트로 바뀌었고 최종 SHA256은 `8f18f5aca1433f221fdcc11a0ef7a4c9f663bc4bc72b7c9b6df44f096f73c738`입니다. LF·BOM 없음도 유지했습니다.

바이트 차이는 실제 토큰 절감이나 모델 행동 개선 측정이 아닙니다. 새로운 기능·호출 정책·설정·설치 경로를 추가하지 않았습니다.

- Sol 6.1 medium이 실제 diff·변경 전 본문·원문 구간·폭·검사 기록을 읽어 의미를 유지하는 정형 수정임을 독립 검토했습니다. 검사 재실행·새 앱 행동 시험과 구분합니다.

## 5. 도구·사용량·시간·복구

기계적 추출·수정·검사·설치는 Luna 6.0 medium, 독립 의미 검토는 Sol 6.1 medium에 배정했습니다. 사용 도구는 PowerShell·Python·Git의 읽기 전용 조회·기존 Markdown 검사기이며 도구별 실제 근거를 비공개 기록에 둡니다.

재개 확인을 위해 Goal을 1회 조회해 `null`을 확인했습니다. 새 Goal 생성·상태 변경·예산 설정과 보고 수치를 위한 사용량 조회는 하지 않았습니다. 실제 모델 토큰 사용량은 미제공이며 전체 작업 시간은 미집계입니다. 단계 기록의 관찰 시각·도구 실행 시간을 전체 작업 시간으로 추정하지 않습니다.

이번 고유한 업데이트의 Git 제외 `private`에 실제 `before/source`·`before/local`·`after/source/work-rules`·`after/local/work-rules`와 별도 manifests를 보존했습니다. before 사본은 skill 파일을 직접 담고 after 사본은 work-rules 하위 폴더에 담는 형식입니다. 복구 경로는 이번 설치 기록과 실제 tree를 따르며 과거 업데이트의 구성을 가정하지 않습니다. 공개 문서에는 실제 개인 경로·계정·raw·전체 설정·자격증명을 복사하지 않습니다.

복구는 현재 사용자 차이를 먼저 대조한 뒤 지정 STYLE 변경만 관리 원본·설치본에 복원합니다. 기존 캐시와 이후 사용자 파일·다른 skill·공통 기록·설정을 삭제하거나 덮어쓰지 않습니다.
