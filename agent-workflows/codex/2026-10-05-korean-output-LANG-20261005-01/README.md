# 한국어 출력 규칙 반영

## 1. 요청과 변경

LANG-20261005-01: 사용자 요청에 따라 개인 응답·진행·완료 보고에 일본어·한자 표기를 사용하지 않고 자연스러운 한국어로 작성하며 전송 전에 혼입을 확인하도록 추가했습니다. 명시적인 원문·번역 요청과 정확성 보존이 필요한 코드·명령·경로·식별자·직접 인용은 보존합니다.

[개인 지침](../../../codex_windows/AGENTS.md)과 [work-rules](../../../codex_windows/skills/work-rules/SKILL.md)에 같은 규칙을 반영했습니다. 중앙 정책과 다른 저장소 지침은 변경하지 않았습니다.

## 2. 검증과 설치

- 원본과 기존 설치본의 work-rules 전체 44파일이 동일함을 확인하고 전체 폴더·개인 지침·설정과 해시를 Git 제외 private/before에 보존했습니다.
- 원본 skill 공식 구조 검사, Markdown 2파일의 링크 15개·헤딩 7개·표현 검사를 통과했습니다. 기존 링크·앵커는 변경하지 않았습니다.
- 검증 후 work-rules 전체 폴더를 반영하고 44파일 목록·해시 일치를 확인했습니다. 개인 AGENTS는 이번 규칙만 병합하여 기존 나머지 본문과 설정을 보존했습니다.
- 한국어 보고, 정확한 경로·코드 보존, 명시적 원문 요청의 경계를 검토했습니다. 새 세션의 자동 적용·지속적인 언어 혼입 방지는 아직 행동으로 검증하지 않았습니다.

## 3. 복구와 게시

private/before·after와 해시로 이번 변경을 식별합니다. 복구 시 이후 변경을 먼저 대조하고 이번 문구만 되돌리거나 병합합니다. 다른 skill·설정과 역사 보존본은 변경하지 않았습니다. 담당 문서만 main에 일반 게시하고 원격 SHA는 private 게시 기록과 완료 보고에 남깁니다.
