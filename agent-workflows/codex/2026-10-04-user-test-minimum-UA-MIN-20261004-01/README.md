# UA-MIN-20261004-01 사용자 테스트·개입 최소화

## 1. 요청과 범위

사용자가 제시한 사용자 테스트·개입 최소화 본문 7개 항목을 [개인 AGENTS 배포 원본](../../../codex_windows/AGENTS.md)에 그대로 추가합니다. agent가 가능한 검증을 먼저 완료하고 사용자 확인은 직접 판단이 필요한 최소 항목으로 한정하며, 준비된 실행 대상의 절대 경로·파일명·방법·예상 결과를 안내합니다. 현재 사용자의 명시한 범위와 기존 운영·데이터 적용 기준을 유지합니다.

담당·예정 commit 파일은 개인 AGENTS 배포 원본, [Windows TODO](../windows/TODO.md), [CHANGELOG](../../../CHANGELOG.md), 이 README와 validation.json입니다. 로컬 개인 AGENTS의 기존 경로 안내는 사용자 차이로 보존합니다. 이번 범위에서 skill 구현·config·system/plugin·저장소별 정책·게임 실행본·INI·DB를 수정하지 않습니다.

## 2. 적용 순서

1. 실제 Git 루트·yunli·기존 변경·원본/로컬 차이를 확인합니다.
2. 담당 이전 파일과 로컬 개인 AGENTS 전체를 작업별 private/before에 보존하고, 보호 파일 해시와 Git 제외를 확인합니다.
3. 배포 원본에 요청한 문구를 추가하고 Markdown·문구 대조·보안·기존 본문 보존을 검사합니다.
4. 검증한 변경만 로컬 AGENTS에 병합합니다. 기존 관리 경로 안내와 다른 개인 파일의 해시를 대조하고 private/after와 manifest로 전후 근거를 보존합니다.
5. 검토한 담당 파일만 yunli에 commit·일반 push하고 원격 SHA와 사용자 확인용 commit 링크를 보고합니다. main은 별도 범위입니다.

## 3. 검증과 미실행

실제 검사 대상 수·도구·exit·본문 보존·로컬 반영·보호 파일 대조는 [validation](validation.json)에 기록합니다. 배포용 AGENTS는 기존 푸터 없는 양식을 유지하고 관리 기록은 기존 날짜·라이선스 양식을 따릅니다. 검사기 실행 자료와 실제 개인 경로·원형 백업은 Git 제외 private에만 보존합니다.

로컬 파일 배치·문구 일치 검사는 새 세션의 자동 로딩이나 실제 행동 검증과 구분합니다. 새 세션 대표 행동 관찰은 Windows TODO에서 agent의 후속 확인으로 유지하며 이번 문구 추가를 이유로 사용자에게 별도 시험을 요청하지 않습니다. CI·main 반영·다른 환경 설치·게임 기동/적용은 이번 검증으로 완료 처리하지 않습니다.

## 4. 복구와 게시

private/before와 현재 파일을 대조해 이번 추가 본문만 선택 복구합니다. 갱신 후 사용자·다른 agent가 수정한 내용을 보존하고 로컬 개인 경로 안내를 일괄 교체하지 않습니다. 게시 후 원본 복구는 검토된 revert로 처리하며 원격 SHA 확인 자료는 private 게시 receipt에 보존합니다. 실제 게시 commit은 yunli 이력과 최종 사용자 보고에서 확인합니다.
