Luna workflow 조사에서 사라진 codex/payload 경로와 과거 관찰의 현재 상태 오해를 확인했습니다. 숨김 폴더 검색을 빠뜨려 사본이 없다는 초기 보고가 있었으나, 주 agent가 .agents/skills의 네 파일을 직접 확인해 정정했습니다. 파일·JSON·관찰 상태를 신규 설치 결과로 갱신하지 않습니다.

원문 스킬 조사에서는 Kiro URI·hook·memory·외부 경로와 스킬 간 의존, 잠금 획득·해제와 승인 지시의 모순을 확인했습니다. 전체 원문을 보존하고 Codex 호환 규칙·로컬 참조·안전한 대체 절차를 추가합니다. 필수 자료는 같은 폴더에 포함하고 운영 명령은 실환경 권한 없이 실행하지 않습니다.
