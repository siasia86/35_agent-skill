# Claude 에이전트 구성

## 저장소 사용자 지침

- [Claude 최초 적용 전 점검](docs/CLAUDE_SETUP_GUIDE.md)
- [Claude 업데이트 전 점검](docs/CLAUDE_UPDATE_GUIDE.md)

Claude용 Agent·Skill·Prompt와 적용·검증 자료를 관리하기 위한 예약 영역입니다. 각 AI 도구에 맞춘 에이전트 설정 최적화와 [저장소의 구성 원칙](../README.md#1-목적)을 따릅니다.

현재는 원본 경로와 공개 동기화 허용 목록을 확정하지 않았습니다. 따라서 이 디렉토리는
예약 영역이며 실제 Claude 파일, manifest와 동기화 스크립트를 추가하지 않습니다.

향후 Claude 구성도 31 저장소의 설치·설정·실행 없이 사용할 수 있도록 작성합니다. 필요한 원본 경로·공개 복사 범위·제외 항목·라이선스·도구가 지원하는 개인/저장소별 설치 위치·적용 및 검증 방법·복구 절차·관리 책임을 확인한 뒤 활성화합니다. 동기화 기능을 제공할 때는 방향·명령·검증 방법을 함께 확인합니다. 독립 사용 원칙을 명시하는 것으로 실제 Claude 구현이나 동작 검증이 완료되지는 않습니다.

현재 작업공간에 31에서 관리하는 설정이 적용되어 있으면 그 적용 범위와 지침에 따라 함께 사용합니다. 31 연동을 사용할 때는 적용되는 [동기화 정책](https://github.com/siasia86/31_governances/blob/yunli/.governance/repository/sync_policy.md)과 [Repository Governance](https://github.com/siasia86/31_governances/blob/yunli/.governance/repository/README.md)를 확인합니다. 그 밖의 작업공간에서도 사용자 지시·저장소 지침·현재 권한을 기준으로 구성합니다.

공통 적용 절차와 환경·작업공간별 결과는 [agent-workflows](../agent-workflows/README.md#41-환경과-작업공간별-기록)에서 관리합니다. 실제 설치·발견·대표 행동 검증 상태는 도구별로 확인한 결과를 기록합니다.
