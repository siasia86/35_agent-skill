# Kiro 최초 적용 지침

## 1. 대상과 범위

이 저장소의 Kiro Agent·Skill을 참고하거나 자신의 환경에 선택 적용하는 사용자를 위한 지침입니다. 문서 열람만으로 설치나 수정이 승인되지는 않습니다. [공통 최초 적용 절차](../../agent-workflows/common/USER_TODO.md)를 함께 읽습니다.

이 문서는 공용 절차입니다. 체크리스트를 개인 작업 기록에 복사하고 결과·백업 위치·미완료 항목을 그 기록에 남깁니다. 개인 경로·자격증명·실행 결과를 공용 지침서에 누적하지 않습니다.

## 2. 적용 전 확인

- [ ] 저장소 루트에서 Git 상태와 사용할 commit을 확인합니다.
- [ ] 실행 계정·Kiro 버전·실제 runtime 경로와 기존 설정을 확인합니다.
- [ ] 저장소의 kiro/와 사용자 runtime을 구분합니다. 보존 원본은 수정하지 않습니다.
- [ ] [공개 미러 목록](../manifests/kiro_files.txt)을 읽고 필요한 agent·skill·prompt·의존 파일을 선택합니다.
- [ ] 공개 미러 목록은 설치 전용 목록이 아닙니다. 문서·보존 스크립트를 자동 설치하지 않습니다.
- [ ] docs/·작업 기록·개인 설정·세션·자격증명은 runtime 복사 대상에서 제외합니다.

## 3. 선택 적용

1. 선택 파일별 원본·목적지·기존 파일 유무·해시를 기록합니다. 참조하는 skill·hook·설정 파일이 실제로 준비되어 있는지 확인합니다.
2. runtime 검색 밖 staging에서 선택 파일의 문법·참조·권한·라이선스를 검토합니다.
3. 기존 runtime을 승인된 위치에 백업합니다. 최초 설치로 대상이 없으면 기존 대상 없음과 신규 파일 복구 방법을 기록합니다.
4. 선택 파일만 대상으로 하는 복사 계획과 dry-run을 검토합니다. kiro/ 전체 복사나 삭제 동기화는 하지 않습니다.
5. 변경 대상·백업·권한을 확인하고 승인된 범위만 적용합니다. 권한 실패를 sudo·chown으로 자동 우회하지 않습니다.
6. 설치된 agent·skill의 로딩과 대표 작업을 확인합니다. 현재 client에서 지원하는 실행·전환 방법을 먼저 확인합니다.

kiro/03_home-sjyun-kiro.sh는 명령 문자열을 출력할 뿐 설치하지 않습니다. 출력에는 rsync 미리보기 뒤 실제 chown 명령이 포함되므로 복사하여 실행하지 않습니다. 이 지침은 설치 자동화 스크립트가 아닙니다.

## 4. 검증과 복구

- [ ] 선택 목록과 실제 설치 파일·해시·참조를 대조합니다.
- [ ] Agent JSON, Skill 문서와 관련 shell의 문법을 검사합니다.
- [ ] 실제 로딩·역할·권한을 시험하고 정적 검사와 구분해 기록합니다.
- [ ] 필수 파일 누락이나 읽기 실패는 전체 통과로 기록하지 않습니다.
- [ ] 실패하면 추가 적용을 멈추고 해당 설치분만 검증된 백업으로 복구합니다.
- [ ] 신규 파일은 설치 기록과 현재 해시를 대조한 뒤 격리합니다. 이후 사용자 변경을 덮어쓰지 않습니다.

저장소 문서 검사는 루트에서 설치된 검사 도구로 수행합니다.

```bash
sia-md-style-check kiro/docs/
sia-md-heading-check kiro/docs/
sia-md-link-check kiro/docs/
git diff --check
```
