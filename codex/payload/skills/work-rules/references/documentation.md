# Personal documentation rules

## 1. Selected conventions

When Korean is selected, use Korean prose and preserve commands, paths, code, and configuration keys. Apply the repository's heading, footer, badge, date, license, diagram, and table conventions only in their stated scope. Existing attribution is not removed merely because new documents do not require a footer.

## 2. Checks and evidence

Use the configured style, heading, and local-link checkers on affected documents. Check table-of-contents anchors, relative links, code-block exclusions, and numbering where applicable. Static local-link success does not establish external URL availability.

Use primary sources for technical claims needing verification. Separate facts, assumptions, and unverified claims. Update a reference directory only when requested or required by the repository; do not automatically create one or update another repository.

Read only the requested task and its necessary prerequisites. Keep detailed findings in one record and link it from TODO or CHANGELOG. A formatting-only edit does not require a factual audit of unrelated claims.
