# README template

Determine the document audience and repository conventions before editing. Cover purpose, prerequisites, installation or setup, use, configuration, verification, troubleshooting or limitations, security considerations, and license/contribution pointers where relevant. Keep examples runnable only when their prerequisites and safety constraints are stated.

Do not add badges, statistics, dates, authorship, or copyright footers unless the repository policy requires them and their values are verified. Do not apply README layout rules to skill instructions merely because both are Markdown. Validate local links and commands where possible; identify facts and links that were not verified.
