# Windows 개인 Codex 현황의 이전 진입점

## 1. 현재 원본 위치

사용자 요청으로 개인 적용 환경 이름을 `pc01_codex-app-home`으로 정하고 현행 설치 사본·관찰 metadata·검증 기록을 [Codex 개인 적용본](../../agent-workflows/codex/README.md)으로 통합했습니다. 이전 `codex-windows-personal`은 같은 환경의 과거 별칭입니다.

- [실제 개인 설치와 같은 경로의 skill 본문](../../agent-workflows/codex/README.md#2-현재-적용-파일).
- [유일한 runtime inventory](../../agent-workflows/codex/pc01_codex-app-home/runtime_inventory.json).
- [최초 설치와 이번 정리 검증 이력](../../agent-workflows/codex/VERIFICATION.md).

이 경로는 이전 링크를 위한 연결 안내입니다. 현행 상태·본문을 이곳에 다시 작성하지 않습니다. 기존 기록은 이동한 검증 문서와 Git 이력에 보존하며 개인 AGENTS·전체 config·자격증명은 게시하지 않습니다.
