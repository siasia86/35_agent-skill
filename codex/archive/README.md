# Codex 보존 자산

기존 `codex/.agents/skills`와 `codex/.codex/agents`의 본문을 각각 `skills/`와 `agents/`로 이동했습니다. skill 25개·agent 10개의 원본 bytes는 보존합니다. 이동으로 끊긴 skill 간 상대 링크 세 곳은 열람용 SKILL.md에서 정리하고 문서 메타데이터를 붙였습니다. 해당 원문을 SKILL.md.original로 함께 보관합니다. 대응표의 original_path·original_sha256은 보존 원문, path·sha256은 현재 열람본입니다. 이 경로는 Codex의 기본 자동 발견 위치가 아닙니다.

[경로·해시 대응표](PATH_MAP.json)는 이전 경로를 현재 파일에 연결합니다. [최초 복사 manifest](../BASELINE_MANIFEST.json)는 과거 복사 기준이므로 수정하지 않습니다. 보존본의 과거 hook·권한·경로·완료 기록은 현재 실행 지시나 설치 근거가 아닙니다. 배포 후보는 [payload 매핑](../PAYLOAD_MAP.md)에서 선택합니다.
