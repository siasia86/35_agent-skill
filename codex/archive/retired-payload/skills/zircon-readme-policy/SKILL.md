# Zircon README policy

Use only when repository guidance or repository identity explicitly establishes the Zircon policy. In that scope, do not add statistics, GitHub badges, dates, or copyright/footer blocks merely from a generic README convention. Preserve all other applicable documentation and link-validation rules.

Outside an explicitly identified Zircon repository, do not apply this exception and do not infer it from a similarly named path. This skill does not create or alter repository policy.
