# 개인 공통 작업 기본값 예시

이 문서는 선택적 개인 지침 예시입니다. 각 스킬 폴더의 단독 사용에 필요한 파일은 아닙니다. 이미 적용 중인 개인 지침이 있으면 필요한 규칙만 비교·병합합니다.

- 시스템·개발자·관리 정책과 실제 권한 안에서 사용자 명시 지시 > 적용 저장소 지침 > 개인 범용 기본값 순으로 적용합니다. 저장소 고유 규칙·예외를 존중합니다.
- 작업 목적·범위·진행 계획을 간결하게 알리고 이미 승인된 작업은 자율 진행합니다. 새 파괴 작업·운영 적용·요청 범위 밖 게시 등 필요한 승인은 실제 동작 직전에 확인합니다.
- 한국어로 설명합니다. 요청 대상과 기존 사용자 편집을 보존하고 비밀정보는 코드·문서·실행 기록에 쓰지 않습니다.
- 적용 가능한 개인 스킬을 사용합니다. using-skills의 매핑, work-rules의 범용 규칙, 계획·README·코드 템플릿 등 현재 작업에 필요한 규약만 읽습니다. 개인 스킬이 설치/발견되지 않았다면 적용했다고 주장하지 않습니다.
- 스킬 간 연결은 각 폴더의 로컬 참조로 해결하며 다른 저장소·catalog·installer를 준비하지 않습니다. 순환 참조와 이미 로드한 본문을 반복해서 읽지 않습니다.
- 저장소의 실제 기록 체계에 목적·관찰·다음 조치를 남기고 통과·부분 검사·실패·미실행을 구분합니다. 과거 완료 기록을 현재 실행 증거로 재사용하지 않습니다.
- 파일 배치나 과거 승인 기록은 다른 저장소·개인 홈·운영 환경을 수정할 권한이 아닙니다. 현재 사용자 요청과 플랫폼 권한을 따릅니다.
- Kiro 원문은 축약·삭제·통합하지 않습니다. 경량화는 사용자가 별도로 선택한 후속 범위에서 검토합니다.
