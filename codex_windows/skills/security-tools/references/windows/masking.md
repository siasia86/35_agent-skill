# 마스킹 구현 명세

여기서 설명하는 IP·JSON 업무 도구는 동봉 구현이 아닙니다. 현재 제공된 구현과 map 형식을 확인하고 필요한 기능을 요청 범위에서 구현합니다. 기존 규칙·map의 실제 호환 여부는 격리 fixture로 확인합니다.

## 인터페이스와 저장

기능에 필요한 옵션은 파일 `-f/--file`, 디렉터리 `-D/--dir`, 복원 `-r/--restore`, dry-run `-d`, 상세 `-v`, 버전 `-V`, 확장자 포함/제외 `-i/-e`, quiet `-q`, map 경로 `-m`, 변경 없음 포함 `--all`, JSON 패턴 진단 `--debug`입니다. 실제 구현하지 않은 옵션은 제공한다고 쓰지 않습니다. `--force`는 현재 사용자의 명시 요청 없이 적용하지 않습니다.

map 복원 후에도 보존합니다. `_meta.serial`·source·version과 원본/마스킹 해시 의미를 확인하고 불일치 시 덮어쓰지 않습니다. 기존 map 교체 전 `.bak.N` 백업을 남깁니다. 동일 디렉터리 임시 파일·flush·검증된 교체로 부분 저장을 피하고 실제 Windows 권한/메타데이터 보존 계약을 검증합니다. 파일 mode를 ACL이라고 표시하지 않습니다.

실행 차단용 SAFETY 주석이 있는 도구는 시험 후 원래 상태로 복원합니다. 색상은 마스킹 파일·수량 빨강, 복원·백업 보라, 제외·주의·변경 전 노랑, 변경 후·복원 수량 초록, 행 번호 회색을 사용하고 터미널이 아닌 출력에 색상을 섞지 않습니다. 비밀 원문을 색상 출력 예시로 사용하지 않습니다.

## IP 마스킹

실제 공인 주소와 사설·예제·특수 목적 주소를 구분하고 버전값처럼 `-`·`_`에 인접한 값의 오탐을 확인합니다. 예제 주소 풀은 `192.0.2.0/24` → `198.51.100.0/24` → `203.0.113.0/24`로 순차 배정하며 기존 명세의 최대 762개와 할당 정책을 실제 구현과 대조합니다. 고갈·중복·재실행을 검증합니다.

map 이름은 `<source>.map.ip.json`입니다. 실제 제공된 `SKIP_EXTS`, `SKIP_FILES`, `SKIP_TARGETS`와 민감 설정·복원 map 제외를 유지합니다. `.git` 등 관리 자료·키·세션 자료를 업무 입력으로 스캔하지 않습니다.

## JSON 마스킹

기존 명세는 18개 정규식과 17종이라고 설명하지만 실제 자원 목록은 16종입니다: `ACCOUNT-ID`, `BUCKET`, `VPCE-ID`, `VPC-ID`, `SUBNET-ID`, `SG-ID`, `ENI-ID`, `INSTANCE-ID`, `ELB-NAME`, `RDS-EP`, `CF-DIST-ID`, `NAT-GW-ID`, `RTB-ID`, `IGW-ID`, `IP`, `DOMAIN`. 누락 항목·정규식을 추정으로 만들지 않고 실제 구현 확인 필요로 남깁니다.

대체값은 `<TYPE-N>` 형태, map은 `<source>.map.json`, metadata는 `_meta`에 둡니다. JSON 유효성, 같은 값의 안정적 매핑, 예외값, 기존 placeholder 재처리, 순환 복원과 미제공 map 호환을 검증합니다.

## 점검과 검증

클라우드 9항목과 Git 5항목은 본문 범위를 사용합니다. 16진수·버전·날짜·`ULL` 상수·이미지 ID의 오탐을 실제 문맥과 구분합니다. 제외 설정은 현재 제공된 경로·예외만 사용하고 실제 비밀을 예외값으로 추가하지 않습니다.

Python 문법과 실제 동작을 구분해 격리 fixture에서 mask → restore round-trip, 두 번째 mask의 멱등성, 해시/serial 불일치 차단, 기존 map 호환, 저장 실패·권한·동시성, map 백업·보존을 확인합니다. 문법만 통과한 도구를 운영 마스킹 통과로 보고하지 않습니다.
