# Terraform 변경 계약

실제 업무에 Terraform이 사용될 때만 Windows CLI·프로젝트·workspace·backend·계정·권한을 확인합니다. 없는 도구를 자동 설치하지 않습니다.

적용 전에 plan의 생성·변경·삭제·교체와 의존성을 검토합니다. saved plan에는 비밀정보가 있을 수 있으므로 비공개 승인 경로에 보존합니다. 검토한 plan·대상과 실제 적용이 일치하고 현재 승인이 있을 때 적용합니다. plan 검토는 적용 권한을 추가하지 않습니다.

state backup은 backend의 실제 지원 방법과 출력 인코딩을 확인해 비공개로 보존합니다. PowerShell 기본 `>`로 state bytes를 임의 변경하지 않습니다. state는 리소스·데이터 백업이 아닙니다.

state mv·import·대상 한정은 정당한 목적·실제 소유·도구 계약이 있을 때만 사용합니다. `-target`은 일반 분할의 기본값이 아니며 예외 사용 뒤 전체 plan으로 누락 변경을 확인합니다. 전체 apply를 자동 추가하지 않습니다.

적용 뒤 리소스·서비스·지표와 전체 plan의 기대 정합성을 확인합니다. `plan -detailed-exitcode`는 0 변경 없음, 2 변경 있음, 1 오류이며 2를 안전 승인으로 사용하지 않습니다. 실제 장애는 다음 적용을 멈추고 증거 보존·원인 조사·복구를 먼저 합니다.
