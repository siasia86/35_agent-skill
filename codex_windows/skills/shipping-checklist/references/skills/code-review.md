
# 코드 리뷰

## 검토 절차

변경 의도·요구사항·지원 환경을 확인하고 요청한 파일 전체의 실제 코드와 호출 경로를 검토합니다. 읽기 전용 리뷰에는 수정·commit·push·설치를 포함하지 않습니다. 역사 결함을 현재 결함으로 재보고하지 않으며 미지원으로 명시된 플랫폼을 지원 결함으로 오인하지 않습니다.

| 영역      | 확인할 내용                                                              |
|-----------|--------------------------------------------------------------------------|
| 정확성    | 요구와 로직의 일치, 빈 입력·경계·반환값·타입·예외 경로                   |
| 보안      | 비밀 하드코딩, 입력 검증, 인젝션·경로 탈출, 인증·권한, 로그 노출         |
| 오류 처리 | 무조건 예외 삼키기, 외부 실패 전달, 유용한 오류, 정리·복구 경로          |
| 성능      | N+1·중첩 반복, 대용량 전체 로드, 핸들 누수, 비동기 차단                  |
| 동시성    | 공유 상태·경쟁·잠금 순서·원자성·부분 쓰기                                |
| 유지보수  | 기존 스타일, 명확한 이름, 실제 중복·복잡도, 필요한 설명                  |
| 시험      | 정상·오류·경계·분기·회귀, 실제 외부 의존에 맞춘 대역                     |
| 호환성    | 지원 버전·의존성·Windows 경로·인코딩·개행·파일 공유 계약                 |
| 인프라    | 변수·설명·이름·태그의 저장소 기준, 최소 권한·암호화·데이터 보호·드리프트 |

Windows 특성은 [상세 검토](../windows/review.md)를 필요한 경우 읽습니다. 발견 사항은 실제 재현 또는 제어 흐름 근거, 파일·행, 발생 조건·영향·수정 방향을 포함합니다. 코드 전체나 비공개 증거를 복사하지 않습니다.

## 결과

저장소가 지정한 우선순위 형식을 우선합니다. 지정이 없으면 🔴 버그·보안 위험, 🟡 개선, ☆ 선택 제안으로 구분해 `심각도 / 위치 / 발생 조건·문제 / 수정 제안`을 보고합니다. 중대한 위험은 병합 전 해소 대상으로 표시하고 검토 근거 없는 의심을 결함으로 단정하지 않습니다. 발견 사항이 없더라도 실행한 검사와 남은 검증 한계를 밝힙니다.
## 실행 기준

현재 사용자 요청·적용 저장소 지침·플랫폼 정책과 실제 권한을 따릅니다. 저장소 작업은 실제 Git 루트·기존 변경·하위 지침부터 확인하고 다른 작업과 비공개 자료를 보존합니다. 검토·명세 작성은 설치·운영 적용·게시 권한을 추가하지 않으며 이미 승인된 범위는 반복 확인하지 않습니다.

Windows PowerShell을 사용하고 파일 작업은 확인한 절대 경로와 `-LiteralPath`로 처리합니다. Python이 필요한 경우 실제 Python 3.11 이상을 확인해 `python -X utf8 -B`로 호출하고 UTF-8 입출력을 명시합니다. PowerShell 오류와 외부 명령의 `$LASTEXITCODE`를 각각 판정합니다. 업무에 필요한 선택 도구만 실제 설치·대상·권한을 확인하며 자동 설치하지 않습니다. Windows 네이티브에서 실행할 수 없는 기능은 범위 밖으로 표시합니다.

한국어로 결과와 실제 근거를 보고하고 통과·부분 검사·실패·미실행을 구분합니다. 폴더 안의 해당 참조만 필요할 때 읽으며 다른 저장소·형제 스킬 설치를 필수로 요구하지 않습니다.
