# 저장소 지침 연결

repo 기록 체계의 출처·충돌을 확인하거나 구조 변경이 요청된 경우에만 읽습니다. 단순 작업 재개는 대상 repo의 현재 작업 항목과 관련 근거로 직접 이동합니다.

## 1. 현재 적용 기준

실제 Git 루트의 적용 AGENTS와 그 문서가 지정한 운영·기록·검증 지침을 따릅니다. 경로가 불명확하면 지정된 INDEX의 관련 항목을 확인합니다. 필수 지침을 읽지 못한 상태를 규칙 부재로 처리하지 않습니다.

문서 역할·상태 전이·기록 위치·결과물 tree·푸터·파일명·게시 branch는 개인 skill에서 정의하지 않습니다. 31의 codex/template은 작성 양식, codex/profile은 대상별 배포 원본입니다. 실제 대상에 적용된 지침과 미배포 중앙 사본·백업을 구분하고 다른 repo의 profile을 자동 적용하지 않습니다.

## 2. 중앙 조회와 독립 사용

31 조회는 정책 출처 확인·중앙 개정·배포 작업에 필요한 경우만 수행합니다. 중앙 위치는 현재 작업공간 안내 또는 사용자 지정 위치에서 확인하며 특정 드라이브·옛 profiles 경로를 필수 의존성으로 두지 않습니다. 일반 실행을 위해 중앙 clone·설치·동기화를 요구하지 않습니다.

대상에 지침이 없다면 기존 문서와 현재 요청을 기준으로 필요한 최소 기록을 유지합니다. 지정되지 않은 관리 폴더·양식·푸터를 초기화하지 않습니다. profile 배포와 원문 읽기는 설치·운영 적용·다른 repo 수정 승인이 아닙니다.

개인 skill 자체의 갱신·백업은 [보존·교체 절차](skill-maintenance.md)를 사용합니다. 제품·도구·sealed 자료·개인 runtime의 고정 경로는 해당 계약을 유지합니다.
