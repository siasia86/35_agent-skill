
# Python 스크립트

## 템플릿 사용

[script_template.py](../../scripts/script_template.py)를 실제 대상 업무에 맞춰 복사·개선합니다. 먼저 `transform_content()`에 요청한 멱등 변환을 구현합니다. 템플릿 자체의 dry-run은 입력 검증·처리 예정 경로만 보여 주며 실제 변환을 보장하지 않습니다. 일반 실행은 미구현 변환을 오류로 처리합니다. 복원 기능은 구현되지 않았으므로 `-r`을 광고하지 않습니다.

파일 순서는 모듈 설명·날짜 `VERSION`·한 줄 import·logger·colors·constants·utilities·core functions·entry입니다. 표준 라이브러리와 외부 의존을 구분하고 함수 요약 docstring, 분리한 `parse_args()`, `main()`의 명시 종료 코드와 KeyboardInterrupt 130을 유지합니다. 실제 패턴의 `re.compile()`은 모듈 상수로 두고 함수 안 반복 import를 피합니다.

도움말은 기능 한 줄, 실제 옵션, Examples 2~4개, Notes의 멱등성·로그·제한을 담습니다. `argparse.RawDescriptionHelpFormatter`를 사용합니다. `-V/--version`을 유지하고 `-d/--dry-run`, `-v/--verbose`, `-q/--quiet`, `-f/--file`, `-D/--dir`은 실제 구현에 맞춰 제공합니다. 선택적 `-l`, `-o`, `-r`, `-P`는 구현한 경우만 노출합니다. SAFETY 주석은 임시 실행 차단 용도로 유지하며 시험 후 원래 상태로 되돌립니다.

100줄 이하 단일 기능은 `print()`와 단순 `main()`을 사용할 수 있습니다. 파일 처리·여러 모드에는 logger와 분리된 입력·처리 함수를 사용하고 복잡한 스크립트는 모듈 분리를 검토합니다. 줄 수만으로 불필요한 구조를 강제하지 않습니다.

현재 옵션·종료·파일 저장 제한은 [템플릿 계약](../windows/template-contract.md)을 읽습니다. Python 하위 실행도 `[sys.executable, '-X', 'utf8', '-B', ...]` 인자 배열을 사용합니다. 입력 경로를 셸 코드로 조합하지 않습니다.

## 검증

문법 검사와 실제 실행을 구분해 도움말·정상·누락·잘못된 종류·혼합 batch·dry-run·멱등성·실패 정리를 격리된 비식별 fixture에서 검증합니다. 성공 문구만으로 파일 변환·복원·메타데이터 보존 성공을 주장하지 않습니다.
## 실행 기준

현재 사용자 요청·적용 저장소 지침·플랫폼 정책과 실제 권한을 따릅니다. 저장소 작업은 실제 Git 루트·기존 변경·하위 지침부터 확인하고 다른 작업과 비공개 자료를 보존합니다. 검토·명세 작성은 설치·운영 적용·게시 권한을 추가하지 않으며 이미 승인된 범위는 반복 확인하지 않습니다.

Windows PowerShell을 사용하고 파일 작업은 확인한 절대 경로와 `-LiteralPath`로 처리합니다. Python이 필요한 경우 실제 Python 3.11 이상을 확인해 `python -X utf8 -B`로 호출하고 UTF-8 입출력을 명시합니다. PowerShell 오류와 외부 명령의 `$LASTEXITCODE`를 각각 판정합니다. 업무에 필요한 선택 도구만 실제 설치·대상·권한을 확인하며 자동 설치하지 않습니다. Windows 네이티브에서 실행할 수 없는 기능은 범위 밖으로 표시합니다.

한국어로 결과와 실제 근거를 보고하고 통과·부분 검사·실패·미실행을 구분합니다. 폴더 안의 해당 참조만 필요할 때 읽으며 다른 저장소·형제 스킬 설치를 필수로 요구하지 않습니다.
