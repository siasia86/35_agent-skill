
# 보안·마스킹

## 도구 경계

마스킹·복원·보안 점검에 적용합니다. 개인 마스킹·보안 scanner·외부 config는 이 폴더에 실행 구현으로 제공되지 않습니다. 현재 제공된 실제 도구를 확인하거나 요청 범위에서 구현하고, 수동 점검과 scanner 실행 결과를 구분합니다. 특정 도구의 정규식·map 호환성을 추정으로 보장하지 않습니다.

마스킹 구현 요청이면 [마스킹 명세](../windows/masking.md)를 읽고 비식별 fixture로 round-trip·멱등성·map 호환·원자적 저장·권한·serial/해시를 검증한 뒤 승인된 대상만 처리합니다. 대량 작업은 대상과 복구 방법을 먼저 명시합니다. 외부 설정이 없으면 다른 저장소에서 찾거나 새로 만들지 않고 제공된 예외만 사용합니다.

map에는 원본 민감정보가 있으므로 비공개에 보존하고 공개 출력·staging·동기화에서 제외합니다. 복원 전 map 형식·serial·원본/마스킹 해시 의미를 확인합니다. 불명확하거나 해시가 다르면 중단하고 원본을 덮어쓰지 않습니다. `--force`는 현재 사용자가 명시 요청한 범위에만 적용하며 복원 후 map을 지우지 않습니다.

## 보안 점검

요청한 파일·저장소의 실제 입력을 필요한 범위에서 읽기 전용 검색·Python·Git 조회로 확인하고 비밀값을 출력하지 않습니다.

- 클라우드 자료 9항목: access key, secret key, 계정 ID, ARN, endpoint ID, 공개 IP, 리소스 ID, 저장소 이름, 추적된 복원 map.
- Git 자료 5항목: 민감 IP, password·key, 클라우드 계정 ID, 대용량 파일, 민감 파일명.

버전값·16진수·날짜·언어 상수·예제값의 오탐과 실제 민감값을 구분하고 제외 이유를 기록합니다. 실제 scanner를 실행하지 않은 결과는 수동 검사로 보고합니다. 업무에 필요하지 않은 Docker·클라우드 인증·scanner 설치를 시작하지 않습니다.

문서 검사가 실제 필요한 경우 [동봉 Markdown 검사](../windows/markdown-checks.md)를 읽고 `scripts/md-style-check.py`, `scripts/md-heading-check.py`, `scripts/md-link-check.py`와 공통 `scripts/md_common.py`를 사용합니다. 저장소 지정 검사기·설정을 우선하며 이 검사는 보안 scanner가 아닙니다.
## 실행 기준

현재 사용자 요청·적용 저장소 지침·플랫폼 정책과 실제 권한을 따릅니다. 저장소 작업은 실제 Git 루트·기존 변경·하위 지침부터 확인하고 다른 작업과 비공개 자료를 보존합니다. 검토·명세 작성은 설치·운영 적용·게시 권한을 추가하지 않으며 이미 승인된 범위는 반복 확인하지 않습니다.

Windows PowerShell을 사용하고 파일 작업은 확인한 절대 경로와 `-LiteralPath`로 처리합니다. Python이 필요한 경우 실제 Python 3.11 이상을 확인해 `python -X utf8 -B`로 호출하고 UTF-8 입출력을 명시합니다. PowerShell 오류와 외부 명령의 `$LASTEXITCODE`를 각각 판정합니다. 업무에 필요한 선택 도구만 실제 설치·대상·권한을 확인하며 자동 설치하지 않습니다. Windows 네이티브에서 실행할 수 없는 기능은 범위 밖으로 표시합니다.

한국어로 결과와 실제 근거를 보고하고 통과·부분 검사·실패·미실행을 구분합니다. 폴더 안의 해당 참조만 필요할 때 읽으며 다른 저장소·형제 스킬 설치를 필수로 요구하지 않습니다.
