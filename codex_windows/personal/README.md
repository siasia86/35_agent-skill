# Codex Windows 개인 구성 안내

현재 안내 문서만 있으며 개인 `AGENTS.md`·config·skill 설치본은 만들지 않았습니다. 실제 개인 설정을 이 영역에 복사하지 않습니다.

## 1. 적용 범위

향후 개인 지침 예시는 기존 지침과 비교·병합할 수 있는 선택 자료로 설계합니다. 사용자 명시 지시·적용 저장소 지침·개인 기본값의 범위를 플랫폼 정책과 현재 권한 안에서 확인합니다. [Linux 모음](../../codex_linux/README.md)의 예시와 실제 Windows 개인 설정을 구분합니다. 기존 사용자 편집·동명 skill·설치 위치는 별도 확인합니다.

## 2. 설치와 관찰

선택한 Windows skill의 구현·검증이 끝난 뒤 사용자가 지정한 범위에서 설치를 진행합니다. 설치·파일 일치·새 세션 발견·명시 호출·대표 행동은 별도로 기록합니다. 개인 경로·계정·키·config 원문·세션·raw 비공개 증거를 공개 저장소에 복사하지 않습니다. 설정·권한·MCP·모델 변경을 문서 골격 작성의 결과로 취급하지 않습니다.

진행 순서는 [PLAN](../PLAN.md)과 [TODO](../TODO.md)를 따릅니다. 이번 작업의 실제 개인 설치는 미실행입니다.
